Projeto Carro Fácil

HTML, CSS, Bootstrap e JavaScript explicados de forma simples

Este material explica como o site funciona, o papel de cada arquivo, as principais tags HTML, as regras CSS, as interações JavaScript e os formulários.

Baseado nos arquivos do projeto local. Versão do guia: 18/11/2026.

1. A ideia geral

Um site pode ser comparado a uma casa:

ParteNo siteO que faz
EstruturaHTMLCria títulos, textos, imagens, menus, cards e formulários.
AparênciaCSSDefine cores, fontes, tamanhos, espaços, posições e efeitos.
ComportamentoJavaScriptReage a cliques, envios de formulário, login, cálculo e seleção de imagens.
Biblioteca visualBootstrapOferece classes prontas para botões, cards, alertas e campos.
Conteúdo visualimg/ e audio/Guardam imagens, vídeo e o áudio promocional.

Como o navegador monta a página

  1. Abre o arquivo HTML.
  2. Encontra o CSS ligado pelo elemento <link>.
  3. Aplica as regras visuais do CSS.
  4. Baixa imagens, vídeo e áudio indicados nos atributos src.
  5. Carrega o JavaScript indicado pelo elemento <script>.
  6. O JavaScript procura elementos e adiciona ações a eles.

3. HTML: a estrutura da página

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="css/estilos.css">
  <title>Carro Fácil</title>
</head>
<body>
  Conteudo visivel da pagina
</body>
</html>
Tag ou atributoExplicação simples
<!DOCTYPE html>Informa que o documento usa HTML5.
<html lang="pt-BR">Inicia o documento e informa que o idioma é português do Brasil.
<head>Guarda configurações, título, CSS e informações da página.
<meta charset="UTF-8">Permite acentos como ã, ç e é.
<meta name="viewport"...>Faz a página se adaptar à largura do celular.
<link>Conecta um arquivo externo, neste caso o CSS e o Bootstrap.
<title>Texto que aparece na aba do navegador.
<body>Contém o que o visitante vê.

Tags semânticas

O projeto usa tags com significado, e não apenas caixas genéricas:

  • <header>: cabeçalho.
  • <nav>: menu de navegação.
  • <main>: conteúdo principal.
  • <section>: seção de conteúdo.
  • <article>: conteúdo independente, como um card de carro.
  • <footer>: rodapé.

Classes e IDs

<section class="apresentacao" id="titulo-principal">
  <h1>Encontre o carro ideal</h1>
</section>

class pode ser reutilizada em vários elementos. id identifica normalmente um elemento único. No CSS, classe começa com ponto, e ID começa com cerquilha.

5. Formulários e validação

<form class="formulario-contato p-3" id="formulario-contato">

  <input class="form-control" type="text" id="nome-contato"

  <label for="email-contato">E-mail</label>
  <input class="form-control" type="email" id="email-contato"

ElementoO que faz
<form>Agrupa os campos que serão enviados.
<label>Nome visível do campo. O for aponta para o id.
type="text"Entrada de texto.
type="email"Entrada que precisa parecer um e-mail válido.
requiredImpede o envio quando o campo está vazio.
placeholderTexto de orientação que desaparece quando o usuário digita.

patternDefine um padrão que o valor precisa obedecer.
type="submit"Envia o formulário.
O formulário do projeto é demonstrativo: o JavaScript mostra uma mensagem, mas não envia os dados para um servidor.

6. CSS: aparência e organização

O arquivo css/estilos.css é compartilhado por todas as páginas. Isso evita repetir o mesmo estilo em cada HTML.

Variáveis de cor

:root {
  --azul-escuro: #0b1f4d;
  --azul: #4174e3;
  --fundo: #f3f7fc;
  --branco: #fff;
}

body {
  color: var(--texto);
  background: var(--fundo);
}

:root guarda variáveis globais. var(--fundo) usa o valor armazenado na variável.

Exemplo de regra CSS

.botao-formulario:hover {
  background: var(--azul);
  transform: translateY(-1px);
}

O seletor é .botao-formulario:hover. Ele significa: procure elementos com essa classe quando o mouse estiver sobre eles. As linhas dentro das chaves são as mudanças visuais.

Estados dos campos

form input:focus,
form select:focus,
form textarea:focus {
  border-color: var(--azul);
  outline: 0;
  box-shadow: 0 0 0 3px rgba(65, 116, 227, .2);
}

form input:invalid {
  border-color: var(--vermelho);
}
  • :hover: mouse sobre o elemento.
  • :focus: elemento selecionado pelo clique ou teclado.
  • :invalid: valor não aceito pela validação HTML.

Responsividade

O site usa Flexbox, Grid, clamp() e media queries. Assim, os cards podem ficar lado a lado em telas grandes e empilhados em telas pequenas.

7. A barra horizontal de carros do index.html

Essa é uma das partes que parecem difíceis, mas ela é feita apenas com HTML e CSS. No [index.html], existe uma caixa chamada imagens com vários links, e cada link contém uma imagem e o nome do carro.

<div class="imagens" aria-label="Modelos em destaque">
  <a href="comprar.html#carro-1">
    <img src="img/veiculo-01-estudio.png" alt="Carro prata">
    <span>Fusion 2008</span>
  </a>
  <a href="comprar.html#carro-2">... outro carro ...</a>
</div>

O segredo está nestas regras do estilos.css:

.imagens {
  display: grid;
  grid-auto-flow: column;
  grid-auto-columns: minmax(220px, 1fr);
  gap: 16px;
  overflow-x: auto;
  padding-bottom: 12px;
  scroll-snap-type: x mandatory;
}

.imagens a {
  scroll-snap-align: start;
}
LinhaExplicação simples
display: gridAtiva o sistema de grade do CSS.
grid-auto-flow: columnColoca os cards em uma linha horizontal, em vez de empilhar todos em uma coluna.
grid-auto-columnsDefine a largura de cada card. Cada um tem pelo menos 220 pixels.
minmax(220px, 1fr)O card nunca fica menor que 220px, mas pode crescer quando houver espaço.
gap: 16pxCria espaço entre os cards.
overflow-x: autoQuando não cabe tudo, cria uma barra para rolar para a direita e para a esquerda.
scroll-snap-type: x mandatoryAjuda a rolagem a parar alinhada em cada card.
scroll-snap-align: startDefine o ponto em que cada card deve parar.
A letra x significa o eixo horizontal. Se fosse overflow-y: auto, a rolagem seria vertical.

Como criar uma barra assim em outra página

  1. Crie uma div com uma classe, por exemplo class="lista-horizontal".
  2. Coloque vários cards dentro dela.
  3. Use display: grid e grid-auto-flow: column.
  4. Defina uma largura mínima para os cards.
  5. Adicione overflow-x: auto.
  6. Teste no celular arrastando a lista para os lados.

8. Outras partes difíceis explicadas

Grid de cards

.grade-cartoes-servicos {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}

repeat(3, ...) cria três colunas. 1fr divide igualmente o espaço disponível. Em uma media query, o projeto reduz o número de colunas para caber em telas menores.

Flexbox do cabeçalho

.cabecalho {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 24px;
}
  • display: flex: coloca os elementos lado a lado.
  • align-items: center: centraliza verticalmente.
  • justify-content: space-between: separa logo e menu.
  • gap: cria espaço entre os elementos.

Imagem dentro do card

.imagens img {
  width: 100%;
  height: 170px;
  object-fit: contain;
  background: #eef3fa;
}

width: 100% faz a imagem ocupar a largura do card. height padroniza a altura. object-fit: contain mostra o carro inteiro sem cortar a imagem.

O efeito de aumentar a imagem

.imagens a:hover img {
  transform: scale(1.03);
}

Quando o mouse passa sobre o link, a imagem aumenta para 103% do tamanho original. O seletor tem um espaço: ele significa "a imagem dentro do link que está com hover".

Details e summary

<details>
  <summary>Ver detalhes</summary>
  <p>Descricao do veiculo.</p>
</details>

Essa dupla cria um painel que abre e fecha sozinho. É uma solução simples quando você não precisa programar o clique com JavaScript.

Como criar um botão com ação

<button id="botao-oferta" class="btn btn-primary">
  Ver oferta
</button>
<p id="mensagem-oferta"></p>
var botaoOferta = document.querySelector("#botao-oferta");
var mensagemOferta = document.querySelector("#mensagem-oferta");

botaoOferta.addEventListener("click", function () {
  mensagemOferta.textContent = "Oferta selecionada!";
});

Primeiro o HTML cria o botão e a área da mensagem. Depois o JavaScript encontra os dois elementos e escuta o clique. Quando o clique acontece, textContent troca o texto.

Como criar um novo formulário

  1. Crie o <form> com um id.
  2. Adicione um <label> para cada campo.
  3. Use o tipo correto no <input>.
  4. Adicione required quando o campo for obrigatório.
  5. Crie um botão com type="submit".
  6. No JavaScript, use addEventListener("submit", ...).
  7. Use preventDefault() se o formulário for apenas uma demonstração.

10. Como entender e corrigir problemas

ProblemaO que verificar
Imagem não apareceConfira o caminho, o nome, a extensão e letras maiúsculas ou minúsculas.
Vídeo não carregaUse caminho relativo, como img/video.mp4, e informe type="video/mp4".
CSS não funcionaConfira se existe <link rel="stylesheet" href="css/estilos.css">.
JavaScript não funcionaConfira o caminho js/script.js e o console do navegador.
Botão envia e recarregaAdicione um listener de submit e use preventDefault().
Card fica espremidoUse uma largura mínima e overflow-x: auto ou reduza as colunas no celular.
Campo não aceita o valorVeja required, pattern, minlength e o tipo do campo.

Uma forma simples de investigar

  1. Leia o erro no console do navegador.
  2. Confira se o arquivo realmente existe.
  3. Confira se o caminho é relativo à página HTML.
  4. Teste uma alteração pequena por vez.
  5. Atualize a página e teste novamente.
Exemplo do projeto: o vídeo da página inicial usa um caminho completo do Windows. O ideal é trocar por um caminho relativo dentro da pasta img/, porque o caminho completo só existe no computador que o criou.

12. JavaScript: comportamento

O arquivo js/script.js começa procurando elementos:

var formularioLogin = document.querySelector("#formulario-login");

if (formularioLogin) {
  formularioLogin.addEventListener("submit", function (evento) {
    evento.preventDefault();
    // codigo que reage ao envio
  });
}
TrechoExplicação
varCria uma variável para guardar um valor.
documentRepresenta a página HTML aberta.
querySelectorProcura um elemento pelo seletor CSS.
ifExecuta um bloco somente se a condição for verdadeira.
addEventListenerEscuta um evento, como clique, envio ou mudança.
preventDefault()Impede o comportamento automático do navegador.
textContentAltera o texto de um elemento.
innerHTMLAltera o conteúdo HTML interno de um elemento.

Login e localStorage

localStorage.setItem("carroFacilEmail", email);
var emailSalvo = localStorage.getItem("carroFacilEmail");
localStorage.removeItem("carroFacilEmail");

setItem salva, getItem recupera e removeItem apaga. O valor continua no navegador mesmo depois de atualizar a página.

Simulador

O JavaScript lê o valor do carro, a entrada e a quantidade de parcelas. Depois calcula a parcela com fórmulas e escreve o resultado dentro de uma área da página.

14. Como alterar o site

  1. Para mudar um título ou texto, edite o HTML da página correspondente.
  2. Para mudar uma cor geral, altere as variáveis no início de estilos.css.
  3. Para mudar o visual de todos os botões, edite a regra .botao-formulario.
  4. Para adicionar um carro, copie um card e troque imagem, nome e preço.
  5. Para adicionar um item ao menu, copie um link dentro de <nav> em todas as páginas.
  6. Para criar uma nova interação, procure o formulário ou botão com querySelector no JavaScript.

Cuidados importantes

  • Use caminhos relativos, como img/carro.png, e não caminhos completos do Windows.
  • Mantenha o mesmo nome de arquivo nos links e nas pastas.
  • Não coloque senhas reais no localStorage.
  • Se publicar o site, confira se o Bootstrap e todos os arquivos de mídia carregam.
  • Para o GitHub público, o projeto precisa ser colocado em um repositório e receber um link público.

Conclusão

O Carro Fácil é um projeto front-end completo para fins demonstrativos. O HTML organiza a página, o CSS cria o visual, o Bootstrap ajuda com componentes prontos e o JavaScript adiciona as ações. Entendendo esses quatro papéis, você consegue ler, explicar e modificar o site com segurança.
